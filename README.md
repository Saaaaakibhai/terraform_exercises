# Terraform Exercises 🚀

A collection of hands-on Terraform exercises for learning and practicing **Infrastructure as Code (IaC)**.

---

## 📖 About

This repository contains a series of progressively challenging Terraform exercises — from basic concepts to advanced real-world scenarios. It is designed for self-learning, interview preparation, and skill improvement.

**Goal**: Master Terraform by doing.

---

## 📚 Exercises

| #  | Topic                        | Level         | Description |
|----|------------------------------|---------------|-----------|
| 01 | Terraform Basics             | Beginner      | First resources, providers, variables |
| 02 | Variables & Outputs          | Beginner      | Input variables, locals, outputs |
| 03 | State Management             | Beginner      | Local & remote state, locking |
| 04 | Loops & Meta-Arguments       | Intermediate  | `count`, `for_each`, dynamic blocks |
| 05 | Modules                      | Intermediate  | Writing and using reusable modules |
| 06 | Data Sources & Provisioners  | Intermediate  | Fetching data + running scripts |
| 07 | Remote Backends              | Intermediate  | S3, Terraform Cloud, etc. |
| 08 | Workspaces                   | Intermediate  | Multi-environment management |
| 09 | Terraform Best Practices     | Advanced      | Structure, security, linting |
| 10 | Mini Projects                | Advanced      | Complete real-world projects |

> *More exercises will be added regularly.*

---

## 🛠 Prerequisites

- Terraform CLI (v1.5 or higher recommended)
- Basic knowledge of any cloud provider (AWS/Azure/GCP)
- An active cloud account (for real deployments)
